# Mq's Aseprite Scripts

Collection of `.lua` scripts I've written for Aseprite.

All of these use the CC0 license. Feel free to use, modify, or otherwise mess around with them however you please. No credit or permission is required.

`/utils` contains utility scripts / boilerplate which are intended to be reused with a variety of projects. `/specific` contains scripts designed to accomplish a specific purpose.
